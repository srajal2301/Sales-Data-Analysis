# Sales Data Analysis Using Python

## Project Overview

This project analyzes retail sales data using Python to understand sales performance, profitability, customer purchasing patterns, product performance, and regional trends.

The objective is to transform raw sales data into meaningful insights that can support business decision-making.

## Dataset

The project uses `SuperStoreOrders.csv`, which contains order information, customer details, product categories, sales, discounts, profits, shipping costs, and regional information.

## Tools and Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Project Workflow

1. Loaded the dataset into Pandas.
2. Inspected the dataset's structure and data types.
3. Checked for missing values and duplicate records.
4. Cleaned the sales column and converted it to numeric data.
5. Converted order dates into datetime format.
6. Analyzed sales and profit by category, region, product, and customer.
7. Examined monthly sales trends and profitability.
8. Investigated discount levels and loss-making products.
9. Created visualizations to communicate findings.
10. Prepared a summary of key business metrics.

## Key Analysis Areas

* Overall sales and profit performance
* Category-wise sales and profitability
* Regional sales and profit comparisons
* Monthly sales and profit trends
* Customer and product performance
* Discount and profitability analysis
* Identification of loss-making products

## Visualizations

The project includes charts for:

* Sales by product category
* Monthly sales trends
* Profit by region
* Additional product and profitability comparisons

## Business Value

This analysis can help businesses identify profitable product categories, evaluate regional performance, understand customer contributions, monitor sales trends, and investigate products that generate losses.
